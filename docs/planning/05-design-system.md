# 05. 화면 규칙 — 색·글자·부품

- 상위 문서: 01-prd, 03-user-flow
- 원칙: **교실 뒤에서도 보이게, 폰에서는 엄지로 눌리게**

---

## 1. 두 화면은 완전히 다른 물건이다

| | 교사 화면 (TV) | 모둠 화면 (폰) |
|---|---|---|
| 보는 거리 | 3~8m 떨어진 교실 뒤 | 30cm |
| 보는 사람 | 30명 동시 | 4~5명이 머리 맞대고 |
| 조작 | 거의 없음 (라운드 시작 정도) | 계속 누름 |
| 기본 글자 크기 | **24px** | 16px |
| 제일 큰 글자 | 64px (라운드 번호, 남은 시간) | 28px |
| 화면 기준 | 1920×1080 가로 | 390×844 세로 |

---

## 2. 색

```
--bg          #0F1720   짙은 남색   (TV 배경 — 형광등 아래 눈부심 방지)
--bg-light    #F5F7FA   밝은 회색   (폰 배경)
--card        #1B2734   카드 (TV)
--card-light  #FFFFFF   카드 (폰)
--text        #E8EDF2   글자 (TV)
--text-dark   #1B2734   글자 (폰)
--muted       #7A8A99   흐린 글자

--gold        #F2B441   코인·배당률·우승        ← 돈에 관한 모든 것
--run         #4FC3F7   말·트랙 진행
--goal        #EF5350   결승선·마감 임박
--ok          #66BB6A   정답·확정 완료
--wait        #FFA726   대기 중·미제출

난이도
--easy        #7CB342   쉬움
--normal      #FB8C00   중간
--hard        #E53935   어려움
```

**색만으로 뜻을 전하지 않는다.** 정답/오답은 색 + 글자(⭕/❌)로 같이 표시한다. 색각이상 학생과, 낡은 TV 색감 둘 다를 위해서다.

---

## 3. 글자

```
글꼴: system-ui, -apple-system, "Apple SD Gothic Neo",
      "Malgun Gothic", "Noto Sans KR", sans-serif
```

외부 글꼴을 불러오지 않는다 — 학교망에서 막히면 글자가 깨지고, 그러면 수업이 멈춘다.

| 쓰임 | TV | 폰 |
|---|---|---|
| 남은 시간·라운드 | 64px 굵게 | 28px 굵게 |
| 제목 | 40px 굵게 | 22px 굵게 |
| 동물 이름·모둠 이름 | 28px | 18px |
| 본문 | 24px | 16px |
| 보조 설명 | 20px | 13px |

숫자(코인·배당률)는 `font-variant-numeric: tabular-nums`로 자릿수를 고정한다. 안 그러면 배당률이 바뀔 때마다 표가 들썩인다.

## 4. 부품

### 4-1. 레이스 트랙 (TV 전용)

**말은 오른쪽에서 왼쪽으로 달린다. 출발선이 오른쪽, 결승선이 왼쪽.**

```
 6/10  🏁░░░░🐆▓▓▓▓▓▓   치타 [1]
 4/10  🏁░░░░░░🦓▓▓▓▓   얼룩말 [2]
        ↑결승선      출발선↑
```

- 방향을 뒤집은 이유: 쓰는 동물 이모지(🐆 🐅 🦓 🐎 🦒 🦘 🐇 🐢)가 대부분 **왼쪽을 보고** 그려져 있다.
  왼쪽 출발 / 오른쪽 결승으로 두면 여덟 마리가 전부 뒷걸음질치는 그림이 된다.
  이모지를 좌우 반전(`scaleX(-1)`)하지 않고 **트랙을 뒤집는 쪽**을 골랐다 (사용자 결정)
- 그래서 레인 배치도 거울처럼 뒤집혀 있다 — **칸수(`n/10`)가 왼쪽**(결승선 옆), **동물 이름·배지가 오른쪽**(출발선 옆).
  뒤집기 전과 같은 짝을 지킨 것이고(원래도 이름은 출발선 옆·칸수는 결승선 옆이었다),
  덤으로 제일 굵은 글자인 동물 이름이 흰 체크무늬 결승선에 붙지 않아 8m 가독성이 산다
- ⚠️ 이 방향은 **세 렌더러가 전부 같아야 한다** — TV PixiJS 무대(`teacher/stage.ts`),
  그 폴백인 CSS 트랙(`teacher.css` + `teacher/main.ts`), 폰 미니 트랙(`team/mini.ts`).
  하나만 되돌리면 `prefers-reduced-motion` 이나 WebGL 없는 TV 에서 폰과 반대로 달린다
- 한 줄 높이 64px, 8줄이 화면 절반을 차지
- 지나온 칸은 `--run`, 남은 칸은 어둡게, 마지막 칸은 `--goal`.
  지나온 거리 막대는 **출발선(오른쪽)에서 말까지** 자란다. 먼지·속도선은 말 **뒤(오른쪽)** 로 흩어진다
- 골인한 동물은 줄 전체가 살짝 빛나고 순위 배지 (단, **정산 전에는 등수를 안 보여준다** — 골인 순서만 보임)
- 이동은 CSS `transition 0.6s`만. 복잡한 연출은 이번 범위 밖

### 4-2. 배당률 전광판 (TV 전용)

| 동물 | 걸린 코인 | 배당률 |
|---|---|---|
| 🐆 치타 | 12 | **2.14배** |
| 🦁 사자 | 3 | **5.80배** |

- 배당률은 `--gold`, 28px 굵게
- 값이 바뀐 줄은 0.4초 동안 배경이 잠깐 밝아진다 (뭐가 움직였는지 보이게)
- 코인이 많이 걸린 순서로 정렬하지 **않는다** — 동물 순서 고정. 순서가 바뀌면 눈이 못 따라감

### 4-3. 모둠 현황 (TV 전용)

```
1모둠 미토콘드리아  ✅ 제출   💰 확정
2모둠 엽록체        ⏳ 푸는중  ⏳
```

- 완료 `--ok`, 대기 `--wait`
- **내용은 절대 안 보인다** — 뭘 골랐는지, 맞았는지는 표시하지 않는다

### 4-4. 난이도 고르기 (폰 전용)

```
┌─────────┐ ┌─────────┐ ┌─────────┐
│  쉬움    │ │  중간    │ │ 어려움   │
│ 힌트 약  │ │ 힌트 중  │ │ 힌트 강  │
└─────────┘ └─────────┘ └─────────┘
```

- 세로 88px 이상 (엄지로 정확히 눌리는 크기)
- 각 난이도 색으로 테두리, 고르면 채워짐
- 한 번 고르면 그 라운드에는 못 바꿈 — 누르기 전 확인 한 번 받는다

### 4-5. 힌트 카드 (폰 전용)

```
┌──────────────────────────────┐
│ 2라운드 · 어려움              │
│ 사자는 1·2·3등 안에 반드시    │
│ 듭니다.                      │
└──────────────────────────────┘
```

- 최신이 위로
- 난이도 색 왼쪽 띠
- 여기가 이 게임에서 **제일 많이 읽히는 화면**이다. **글자 20px, 줄간격 1.8** — 폰의 다른 곳(16px)보다 크게 잡는다. 폰 1대를 4~5명이 가운데 놓고 같이 읽어야 하기 때문 (리뷰 반영)
- 새 힌트가 도착하면 자동으로 이 탭으로 넘어간다

### 4-6. 베팅 입력 (폰 전용)

```
🐆 치타   2.14배    [ − ]  2  [ + ]
🦁 사자   5.80배    [ − ]  0  [ + ]
────────────────────────────────
이번 라운드 3개 중 2개 사용
        [ 베팅 확정하기 ]
```

- `+`/`−` 버튼 각 56×56px
- 3개를 다 쓰면 나머지 `+`가 흐려짐
- 확정 버튼은 `--gold`, 누르면 **되돌릴 수 없다**는 확인을 한 번 받는다
- 확정 후에는 전체가 회색으로 잠기고 "확정됨" 표시

### 4-7. 타이머

- TV: 우상단 64px 숫자. 10초 남으면 `--goal`로 바뀌고 1초마다 살짝 커진다
- 폰: 화면 맨 위 얇은 막대가 줄어드는 방식 (숫자는 작게 옆에)
- **소리는 이번 범위 밖** (Should로 미뤄둠)

---

## 5. 지켜야 할 것

- 버튼은 최소 44×44px (폰), 88px 세로 (주요 동작)
- 누르면 0.1초 안에 눈에 보이는 반응이 있어야 한다. 서버 응답이 늦어도 버튼은 즉시 눌린 티를 낸다
- 서버를 기다리는 동안 같은 버튼을 두 번 못 누르게 잠근다
- 오류 메시지는 뭘 하라는지 적는다: ❌ "오류 발생" → ⭕ "베팅 시간이 지났어요. 다음 라운드를 기다려주세요"
- 폰은 세로만 지원. 가로로 돌려도 세로 배치 유지
- 애니메이션은 0.6초 넘지 않는다. 수업 시간이 아깝다

---

## 6. 안 하는 것

- 다크/라이트 전환 — TV는 어두운 화면, 폰은 밝은 화면으로 고정
- 로고·브랜딩 — 개인 수업 도구다
- 외부 아이콘 라이브러리 — 이모지로 충분하고 인터넷 없이도 뜬다
