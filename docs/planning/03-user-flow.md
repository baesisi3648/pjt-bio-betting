# 03. 수업 흐름 — 종 치고 종 칠 때까지

- 상위 문서: 01-prd, 02-trd

---

## 1. 1차시 (규칙 설명 + 1~3라운드) — 50분

| 시각 | 누가 | 무엇 |
|---|---|---|
| 0~3분 | 선생님 | 교사 화면 열기 → 반 이름·모둠 수·모둠 이름·단원 선택 → **판 만들기** |
| | 앱 | 판 코드(예: `2H4K`) 발급, 모둠별 4자리 암호 발급, 정답 순위·힌트 몰래 확정 |
| 3~5분 | 선생님 | 판 코드를 칠판에, 모둠별 암호를 모둠장에게만 종이로 전달 |
| 5~8분 | 모둠 | 폰으로 주소 접속 → 판 코드 → 모둠 선택 → 암호 4자리 → 입장 |
| 8~13분 | 선생님 | 규칙 설명 (TV 화면 보며) |
| 13~20분 | 전원 | **1라운드** (아래 §3 — 약 7분) |
| 20~27분 | 전원 | **2라운드** |
| 27~34분 | 전원 | **3라운드** |
| 34~41분 | 전원 | **4라운드** (여유가 있으면) |
| 41~48분 | 전원 | 정리 — 지금까지 나온 힌트를 모둠끼리 한 번 맞춰보기 |
| 48~50분 | 선생님 | "다음 시간에 이어서" → 화면에 판 코드 크게 띄우고 종료 |

> 상태는 자동 저장된다. 선생님이 따로 저장 버튼을 누를 필요 없음.

## 2. 2차시 (4~6라운드 + 정산) — 50분

| 시각 | 누가 | 무엇 |
|---|---|---|
| 0~3분 | 선생님 | 교사 화면 → **판 코드로 이어하기** → 지난 시간 상태 그대로 복원 |
| 3~5분 | 모둠 | 폰으로 다시 접속 (판 코드 + 모둠 + 암호) |
| 5~12분 | 전원 | **다음 라운드** (1차시에 3라운드까지 갔다면 4라운드) |
| 12~19분 | 전원 | 그다음 라운드 |
| 19~26분 | 전원 | **마지막 라운드** (마지막이 5였다면 여기서 이미 끝나 있음) |
| 26~36분 | 선생님 | **정산** — 최종 순위 공개, 배당 계산, 우승 모둠 발표 |
| 36~45분 | 선생님 | 오답 많았던 문제 짚어주기 (문제 다시보기 화면) |
| 45~50분 | 전원 | 마무리 — 어느 힌트가 결정적이었는지 이야기 |

> 1차시에 몇 라운드까지 갔는지에 따라 2차시 분량이 달라진다. 라운드가 7분이므로 **어느 쪽이든 2차시 안에 정산까지 끝난다.**

## 3. 한 라운드 안 (약 7분)

```
[선생님이 "라운드 시작" 클릭]
        │
        ▼
① 말 이동 (약 20초)
   TV: 8마리가 이번 라운드 이동량만큼 전진
   폰: 트랙 위치만 갱신 (조작 없음)
        │
        ▼
② 문제 풀이 (90초, 타이머 자동 마감)
   폰: 모둠이 쉬움/중간/어려움 중 하나 선택
       → 그 난이도의 4지선다 문제 표시 → 답 고르고 제출
       → 즉시 채점 결과 표시 (정답이면 힌트 1개 지급)
   TV: 어느 모둠이 제출했는지 현황 표시 (내용은 안 보임)
   ⏱ 90초 지나면 미제출 모둠은 오답 처리, 자동으로 다음으로
        │
        ▼
③ 모둠 토론 (180초, 타이머 자동 마감)   ★ 이 수업의 실체
   폰: 힌트 탭이 자동으로 열림. 지금까지 받은 힌트 전부 보기
       베팅은 잠겨 있음 — 조작할 게 없어야 서로 본다
   TV: "모둠 토론 중" + 타이머만. 트랙과 전광판은 그대로
   교실: 선생님은 돌아다니며 듣는다. 여기서 "조용하던 애가 말하는지"가 갈린다
        │
        ▼
④ 베팅 (60초, 타이머 자동 마감)
   폰: 동물에 코인 배분 (라운드당 최대 3개) → 확정
   TV: 배당률 전광판이 실시간(1~2초 간격)으로 움직임
       + 어느 모둠이 아직 확정 안 했는지 표시
   ⏱ 60초 지나면 미확정 모둠은 베팅 0으로 마감
        │
        ▼
⑤ 라운드 마감 (자동)
   서버가 시트에 상태 저장
   마지막 라운드였으면 → 정산 화면으로
   아니면 → ①로 돌아가 다음 라운드 대기
```

## 4. 모둠 폰에서 보는 흐름

```
[주소 접속]
     │
     ▼
접속 화면 ─── 판 코드 4자리 입력
     │              │ 코드 틀림 → "그런 판이 없어요" 다시 입력
     ▼              │
모둠 고르기 ── 전부 선택 가능 (접속 점유를 두지 않음)
     │
     ▼
암호 4자리 ─── 틀리면 "암호가 달라요" (잠금 없음, 시도마다 1초 지연)
     │
     ▼
┌──────────── 모둠 화면 (탭 3개) ────────────┐
│                                            │
│  [문제]   지금 라운드 문제 풀기             │
│           라운드마다 1번만 제출 가능         │
│                                            │
│  [힌트]   지금까지 받은 힌트 전부 (누적)     │
│           라운드·난이도 표시                │
│                                            │
│  [베팅]   동물 8마리 + 현재 배당률          │
│           코인 배분 → 확정 (되돌리기 불가)   │
│                                            │
│  하단: 보유 코인 / 남은 시간 / 지금 뭘 할 때 │
└────────────────────────────────────────────┘
     │
     ▼ (게임 끝나면)
결과 화면 ── 우리 모둠 최종 코인, 맞힌 순위, 전체 등수
```

**폰이 꺼지거나 새로고침되면**: 접속 화면부터 다시. 판 코드 + 모둠 + 암호를 넣으면 힌트·코인이 그대로 살아 있다.

## 5. 선생님 화면에서 보는 흐름

```
[교사 주소 접속]
     │
     ├─→ 새 판 만들기 ─── 반 이름 / 모둠 수(2~8) / 모둠 이름 / 단원 선택
     │        │
     │        │ 문제 수 부족하면 여기서 경고
     │        │ "이 단원에 어려움 4문항이 모자랍니다. 그래도 시작할까요?"
     │        ▼
     └─→ 판 코드로 이어하기 ─── 코드 입력 → 지난 상태 복원
              │
              ▼
       ┌──────────── 진행 화면 ────────────┐
       │ 상단: 3라운드 / 최대 6  ·  남은시간 │
       │                                    │
       │ [레이스 트랙]  8마리 × 10칸        │
       │                                    │
       │ [배당률 전광판] 동물별 베팅·배당률   │
       │                                    │
       │ [모둠 현황]  1모둠 ✅ 2모둠 ⏳ ...  │
       │                                    │
       │ [라운드 시작] [정산하기]            │
       │ (작게) 정답 순위 보기 — 선생님만    │
       └────────────────────────────────────┘
              │
              ▼
       정산 화면 ── 최종 순위 공개 → 모둠별 계산 내역 → 우승 발표
```

## 6. 어긋났을 때

| 상황 | 어떻게 되나 |
|---|---|
| 모둠 폰이 끊김 | 다시 접속하면 그대로 복구. 진행 중이던 라운드는 남은 시간부터 (점유가 없어 막히지 않음) |
| 선생님이 잠깐 멈춰야 함 | `⏸ 일시정지` — 타이머가 멈추고 학생 화면도 잠긴다. 다시 누르면 남은 시간부터 |
| 모둠이 문제를 안 냄 | 90초 뒤 오답 처리, 힌트 없음, 게임은 진행 |
| 모둠이 베팅을 안 함 | 60초 뒤 베팅 0으로 마감, 코인은 그대로 남음 |
| 남의 모둠 암호를 알아냄 | 막을 방법 없음 — 암호는 종이로만, 모둠장에게만 전달 (운영으로 대응) |
| 문제가 모자람 | **시작 전에** 경고. 그래도 시작하면 앞 라운드 문제를 다시 냄 |
| 선생님 노트북이 꺼짐 | 판 코드로 다시 들어오면 마지막 라운드 시작 시점부터 |
| 학교 인터넷이 끊김 | 게임 진행 불가 — 대비책으로 힌트를 종이에 인쇄해 두는 건 이번 범위 밖 |
| 수업 종이 먼저 침 | 그대로 두고 다음 시간에 이어하면 됨 |
