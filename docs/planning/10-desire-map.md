# 10. 결정 요약 — 뭐가 왜 이렇게 정해졌나

이 문서는 **왜 이런 물건이 됐는지**를 한 장으로 남긴 것이다. 나중에 "이거 왜 이렇게 했더라" 싶을 때 여기부터 본다.

---

## 1. 처음 말한 것 → 다시 정리한 것

| | 내용 |
|---|---|
| **처음 요청** | "더 지니어스 '사기경마' 같은 베팅 게임을 앱스 스크립트로 만들고 싶다" |
| **다시 정리** | "단원 마무리 복습을, 모둠이 단서를 모아 서로 이야기하는 시간으로 바꾸기" |
| **왜 바뀌었나** | 성공의 모습을 물었더니 "조용하던 애들이 말한다"였다. 그러면 이 도구의 목적은 문제를 많이 풀리는 게 아니라 **모둠 대화를 만드는 것**이다. 문제 풀이는 힌트를 얻는 수단이고, 진짜 수업은 힌트를 받은 뒤 2~3분에 일어난다 |

---

## 2. 한 줄

> **단원 진도를 다 뺀 마무리 차시에**, 모둠이 문제를 골라 풀고 얻은 단서로 순위를 추리하게 만들고 싶다. **그래서** 평소 손 안 드는 학생도 모둠 안에서 말하게 되고, 문제만 바꿔 끼우면 학기 내내 다시 쓸 수 있다.

---

## 3. 필수 기능이 이 한 줄과 어떻게 연결되나

| 필수 기능 | 한 줄의 어느 부분을 떠받치나 |
|---|---|
| 힌트 보관함 (M7) | **"단서를 모아 서로 이야기"** — 이게 없으면 기억력 싸움이 되고 대화가 안 생김 |
| 난이도 선택 (M6) | **"모둠이 골라 푼다"** — 수준 차이가 큰 반에서 모두가 참여할 유일한 방법 |
| 배당률 전광판 (M10) | **"남보다 먼저 알아낸다"** — 남들이 어디 거는지 보이는 유일한 창. 눈치싸움 전체 |
| 순위 확정 + 이동 역산 (M2) | **"추리한다"** — 힌트가 거짓이면 추리 자체가 성립 안 함 |
| 힌트 검산 (M3) | 같음. 답이 안 좁혀지면 추리가 아니라 찍기가 됨 |
| 시트 문제 연동 (M4) + 동물·힌트 수정 (M14) | **"학기 내내 다시 쓴다"** — 재사용의 유일한 수단 |
| 모둠 암호 (M5) | **"우리 단서"** — 남의 힌트가 보이면 모둠 대화가 무의미해짐 |
| 판 코드 이어하기 (M1) | **"마무리 차시"** — 50분에 안 끝나므로 2차시 분할이 전제 |
| 타이머 자동 마감 (M12) | 같음. 수업이 밀리면 다음에 안 쓰게 됨 |

## 4. 뺀 것과 그 이유

| 뺀 것 | 왜 |
|---|---|
| 한글/엑셀 자동 변환 | 파일 형식이 제각각이라 만들 품이 큰데, 처음 한 번 손으로 옮기면 끝난다 |
| 수업 후 결과 리포트 | 게임과 별개 기능. 있으면 좋지만 없어도 수업이 굴러간다. 대신 `기록` 탭에 재료는 쌓아둔다 |
| 다른 교사 공유·계정 관리 | "나 혼자, 내 반들"로 확정 → 통째로 불필요. 이 하나로 만들 양이 절반 가까이 줄었다 |
| 학생 개인 기록·로그인 | 모둠 단위 게임. 개인정보를 안 받는 게 학교에서 훨씬 안전 |
| 즉시 반응(실시간 푸시) | 필요한 순간이 베팅 60초뿐이고, 1~2초와 0.1초는 교실에서 구분이 안 된다. 대신 관리할 곳이 두 배가 된다 |
| 애니메이션·효과음·모둠 메모장 | 없어도 게임이 돈다. 시간 남으면 추가 |

## 5. 원본 PDF에서 뒤집은 것

| PDF | 바꾼 것 | 왜 |
|---|---|---|
| 말 이동을 랜덤으로 | **순위를 먼저 정하고 이동을 역산** | PDF 코드대로면 "A가 1등"이라 해놓고 A가 5등으로 들어온다. 게임이 무너진다 |
| 3마리 골인 시 종료 (몇 라운드일지 모름) | **마지막 라운드를 5 또는 6으로 몰래 고정** | 2차시 수업 시간에 맞추려면 예측 가능해야 한다. 긴장감은 5냐 6이냐로 남긴다 |
| 팀 순차 진행 | **모든 모둠 동시 진행** | 6모둠 순차면 라운드당 10분, 50분에 3라운드밖에 못 돈다 |
| 라운드당 3코인 (코드엔 미구현) | **서버에서 실제로 막음** | PDF 코드는 무한 클릭 가능 |
| 정산 계산 없음 | **1등 100%/2등 70%/3등 50% 실제 계산** | PDF 코드엔 정산이 아예 없다 |
| 힌트 랜덤 추출 | **참인 힌트만 + 중복 없음 + 검산** | 거짓 힌트나 중복이 나오면 추리가 안 된다 |

## 6. 갈림길에서 고른 것

| 갈림길 | 고른 것 | 포기한 것 |
|---|---|---|
| 50분에 못 끝남 | 2차시로 나눔 | 한 시간 완결. 대신 저장·복구를 만들어야 함 |
| 학생 참여 방식 | 모둠 폰 | 선생님이 다 조작하는 단순함. 대신 힌트 비밀이 자연스럽게 지켜짐 |
| 앱스 스크립트 vs 외부 서비스 | 앱스 스크립트 + 캐시 | 즉시 반응. 대신 관리할 곳이 하나로 유지됨 |
| 라운드 넘기기 | 타이머 자동 | 선생님 재량. 대신 수업이 안 밀림 |
| 힌트 보안 | 모둠별 4자리 암호 | 종이 나눠주는 수고. 대신 확실함 |
| 정산 규칙 | PDF 그대로 (1·2·3등만) | 하위권 구제. 첫 수업 관찰 후 재검토 |

## 6-2. 리뷰(council) 후 바뀐 것

| 지적 | 결정 | 왜 |
|---|---|---|
| 정산이 "먼저 알아내면 유리"를 지운다 (C1) | **PDF 그대로 최종 배당률 유지** | 규칙이 단순해야 학생에게 설명이 된다. 대신 `bets`에 라운드 번호를 남겨 나중에 바꿀 여지를 둠 |
| 접속 점유 판정이 문서 안에서 모순 (C2) | **점유를 아예 없앰** | 새로고침한 폰이 자기 자신 때문에 막히면 그 모둠은 게임에서 이탈한다. 방어선은 암호 하나로 충분 |
| 캐시 소실 시 라운드 베팅 증발 (C3) | **답·베팅 즉시 기록** (M16) | "우리 코인 어디 갔어요"가 30명 앞에서 터지면 안 된다 |
| 폰 1대에 4~5명 (C4) | **메모장은 `Should` 유지**, 힌트 글자만 20px로 | 만들 양을 늘리는 대신 A4 한 장 나눠주는 수업 운영으로 대신한다 |
| 일시정지가 없다 (C5) | **버튼 추가** (M15) | 첫 수업에 "잠깐 설명 좀" 순간이 반드시 온다 |
| 시드 5가 배당을 극단화 (C6) | **15로 올림** | 시드 5면 최대 배당 29.6배 — 3코인 찍어 맞힌 모둠이 6라운드 추론한 모둠을 뒤집는다. 추론 게임이 복권이 된다 |
| 모둠마다 같은 문제 (C9) | **같은 문제 유지** | 다르게 주려면 단원당 문항이 18개→54개. 준비 부담이 이 도구를 안 쓰게 만드는 게 더 큰 위험 |
| 암호 3회 잠금이 장난 도구 (C10) | **잠금 제거, 1초 지연만** | 모둠 단위로 잠그면 남의 모둠을 계속 잠글 수 있다 |

## 7. 아직 안 풀린 것

첫 수업에서 확인해야 한다.

1. **힌트 밸런스** — 어려움이 얼마나 강해야 하나. 너무 강하면 한 방에 끝나고, 약하면 추리가 안 된다
2. **하위권 모둠이 끝까지 하나** — PDF 정산 규칙(1·2·3등만 인정)이 너무 가혹할 수 있다
3. **접속 시간** — 첫 수업은 접속에만 10분 넘게 걸릴 수 있다. 그러면 1차시 라운드를 2개로 줄인다
4. **모둠 안에서 폰을 한 명이 독점하지 않나** — 독점하면 나머지가 구경만 하게 되어 목적이 무너진다
5. **같은 난이도를 고른 모둠에 같은 문제를 주는 게 맞나** — 옆 모둠 답을 베낄 수 있다 (같은 문제로 가기로 결정. 심하면 전환)
6. **초반에 코인을 안 쓰고 버티지 않나** — 최종 배당률만 쓰기로 한 결과. 다들 마지막에 몰빵하면 게임이 밋밋해진다 (`01-prd §6-2`에 조정 후보 세 가지)
7. **시드 15가 적당한가** — 배당이 여전히 튀면 20, 밋밋하면 10
