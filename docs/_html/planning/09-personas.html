09. 쓰는 사람

  • 상위 문서: 01-prd

주 사용자 — 선생님 (본인)

한 줄

단원 진도를 다 뺀 마무리 차시에, 모둠이 문제를 골라 풀고 얻은 단서로 순위를 추리하게 만들고 싶다. 그래서 평소 손 안 드는 학생도 모둠 안에서 말하게 되고, 문제만 바꿔 끼우면 학기 내내 다시 쓸 수 있으면 좋겠다.

어떤 사람

  • 고2 생명과학 담당. 여러 반을 같은 진도로 나감
  • 수업용 앱을 직접 만들어 본 적이 있다 — 앱스 스크립트 배포도 할 수 있음
  • 새 도구를 만들 의지는 있지만, 수업 준비 시간은 늘 부족

장면

유전 단원 진도를 다 뺐다. 다음 시간이 마무리 차시인데, 프린트 나눠주고 문제 풀리면 어차피 앞자리 몇 명만 손 든다. 뒤에 앉은 애들은 엎드리거나 딴짓한다. 뭔가 다르게 해보고 싶은데, 카훗은 이미 몇 번 써서 애들도 시큰둥하고 결국 빠른 애가 다 먹는다.

하루 중 이걸 쓰는 순간

언제뭘 하나얼마나 걸려야 하나
수업 3일 전시트에 이번 단원 문제 18문항 입력10~15분
수업 당일 아침학생 주소 열리는지 폰으로 확인1분
수업 5분 전판 만들고, 암호 인쇄해서 자름3분
수업 중TV 띄워놓고 라운드 시작만 누름조작 거의 없어야 함
다음 차시판 코드로 이어하기30초
다음 반같은 단원으로 새 판 만들기1분

무서워하는 것

두려움이 기획에서 어떻게 막았나
수업 중에 안 돌아가서 30명 앞에서 망신수업 전 점검표(08-test-plan §7), 학교망 사전 확인, 끊겨도 복구되게
규칙 설명하다 시간 다 감2차시 분할, 타이머 자동 마감
준비가 오래 걸려서 결국 안 쓰게 됨새 단원 준비 = 시트에 18문항 = 10분
애들이 정답을 어떻게든 알아내서 김빠짐정답을 학생 응답에 아예 안 담음 (04-database §8)
한 번 쓰고 다시 안 쓰게 됨문제·동물·힌트를 시트에서 갈아 끼우게

안 하는 것

  • 코드를 처음부터 새로 짜기 — 만들어진 걸 고쳐 쓰는 건 함
  • 외부 서비스에 학생 정보 올리기
  • 수업 중에 노트북으로 뭔가 급하게 고치기

보조 사용자 — 모둠 (학생 4~5명)

한 줄

모둠에 폰 한 대만 있을 때, 문제를 골라 풀고 받은 단서를 친구들과 맞춰보고 싶다. 그래서 우리가 남보다 먼저 1·2·3등을 알아내서 코인을 쓸어 담고 싶다.

어떤 사람들

  • 고2. 성적 편차가 큼. 한 모둠 안에도 잘하는 애와 포기한 애가 섞여 있음
  • 폰은 다 다룰 줄 안다. 설명서를 안 읽는다
  • 이기고 싶어 한다. 게임이라는 걸 알면 진심이 된다

장면

2라운드에 어려움을 골라서 맞혔다. "사자는 1·2·3등 안에 반드시 듭니다"가 떴다. 1라운드에 받은 "치타가 늑대보다 순위가 높습니다"랑 합쳐보는데, 옆 모둠이 갑자기 사자에 3코인을 몰아서 사자 배당률이 뚝 떨어진다. "야 쟤네도 알고 있나 본데?" "그럼 우리는 치타에 걸자, 아직 배당 좋아." 평소 말 없던 애가 "근데 거북이가 아까부터 계속 3칸씩 가는데" 한다.

무서워하는 것

두려움어떻게 막았나
문제를 못 풀어서 아무것도 못 함쉬움 난이도가 있고, 힌트 없이도 베팅은 가능
초반에 지면 끝까지 구경만배당률이 높은 쪽에 걸면 역전 가능. 정산 배율이 결과를 뒤집을 수 있음
우리 힌트를 옆 모둠이 봄모둠별 4자리 암호
폰 끊겨서 그동안 받은 거 다 날아감다시 접속하면 그대로 복구
뭘 해야 할지 모르겠음화면 하단에 항상 "지금 뭘 할 때인지" 표시

이 게임에서 학생이 진짜 하는 일

문제 푸는 시간은 90초, 베팅은 60초다. 하지만 그 사이 모둠이 힌트를 놓고 이야기하는 2~3분이 이 도구를 만드는 이유다.

그래서 힌트 탭은 스크롤 없이 한눈에 들어와야 하고, 배당률은 TV에서 계속 움직여야 한다. 이 둘이 대화를 만든다.

안 만드는 사용자

누구왜 안 만드나
다른 학교 선생님"나 혼자, 내 반들"로 확정. 문제 분리·계정 관리가 통째로 빠짐
학생 개인모둠 단위 게임. 개인 기록·로그인 없음
관리자관리할 게 없음. 시트가 곧 관리 도구
