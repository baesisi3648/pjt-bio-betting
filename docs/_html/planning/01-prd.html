1. 처음 요청과 다시 정리한 문제

처음 요청 (PDF 기준)

"더 지니어스의 '사기경마' 같은 베팅 게임을 구글 앱스 스크립트로 만들고 싶다. 동물 8마리가 달리고, 문제를 맞히면 난이도에 따라 순위 힌트를 받고, 모둠이 코인을 베팅해서 1·2·3등을 맞히면 이긴다."

다시 정리한 한 줄 문제

단원 마무리 복습 시간을, 모둠이 단서를 모아 서로 이야기하는 시간으로 바꾸기.

왜 바뀌었나

기획 대화에서 선생님이 꼽은 답답함은 세 가지였다 — "복습이 지루하다", "생각하는 수업을 하고 싶다", "문제를 재밌게 풀게 하고 싶다". 그리고 성공의 모습은 "조용하던 애들이 말한다" 와 "매번 써도 안 질린다" 였다.

즉 이 도구의 목적은 문제를 많이 풀리는 것이 아니다. 문제 풀이는 힌트를 얻는 수단이고, 진짜 수업이 일어나는 곳은 힌트를 받은 뒤 모둠이 머리를 맞대는 2~3분이다. 이 관점이 아래 모든 결정의 기준이 된다.

카훗·띵커벨을 안 쓰는 이유 (선생님 답변)

항목카훗류와일드 더비
정답의 쓸모맞히면 점수, 정답 즉시 공개, 끝맞히면 힌트를 받고 그걸로 계속 추론
누가 이기나빠르고 잘하는 학생 한 명이 독식문제를 덜 맞혀도 베팅 전략으로 역전 가능
난이도전체가 같은 문제모둠이 쉬움/중간/어려움을 직접 고름
문제범용 퀴즈내 단원 문제은행을 그대로 끼워 넣고 학기 내내 재사용

2. 쓰는 상황

항목내용
언제단원 마무리 차시
얼마나2차시에 나눠서 (1차시: 규칙 설명 + 1~3라운드 / 2차시: 4~6라운드 + 정산)
규모한 반 25~30명, 모둠 5~6개 (2~8모둠까지 지원)
기기교사 노트북 → 교실 TV 1대 + 모둠당 폰/태블릿 1대
쓰는 사람선생님 본인, 본인의 여러 반. 다른 교사 공유·계정 관리는 만들지 않음
문제구글 스프레드시트에 직접 입력 (기존 문제 파일은 손으로 옮겨 붙임)

3. 한 줄 정리

언제: 단원 진도를 다 뺀 마무리 차시에 뭘 하고 싶나: 모둠이 문제를 골라 풀고, 얻은 단서를 맞춰 1·2·3등을 추리해서 코인을 걸게 하고 싶다 뭐가 좋아지나: 평소 손 안 드는 학생도 모둠 안에서 말하게 되고, 문제를 바꿔 끼우면 학기 내내 다시 쓸 수 있다

4. 이번 첫 판 범위

꼭 들어가는 것 (Must)

#기능왜 필수인가
M1판 만들기 / 판 코드로 이어하기2차시로 나누기로 했으므로 저장·복구가 없으면 게임이 성립하지 않음
M2정답 순위 확정 + 이동 역산힌트가 거짓이 되면 게임 전체가 무너짐 (아래 §6 참조)
M3난이도별 힌트 자동 생성 + 검산힌트끼리 모순되거나 답이 안 좁혀지면 추론 수업이 안 됨
M4구글 시트 문제은행 연동"매번 써도 안 질림"의 유일한 수단
M5모둠 폰 접속 (판 코드 + 모둠 + 암호 4자리)모둠별 힌트 비밀 유지가 게임의 전제
M6모둠 화면: 난이도 선택 → 문제 풀이 → 자동 채점힌트를 얻는 유일한 경로
M7모둠 화면: 내 힌트 보관함라운드가 쌓이면 기억으로 못 버팀. 추론 수업의 핵심 도구
M8모둠 화면: 베팅 입력없으면 선생님이 6모둠 베팅을 손으로 대신 입력해야 함
M9TV 화면: 레이스 트랙이게 없으면 그냥 퀴즈
M10TV 화면: 배당률 전광판남들이 어디 거는지 보이는 유일한 창 — 눈치싸움의 전부
M11TV 화면: 모둠 진행 현황동시 진행이라 누가 아직 안 냈는지 봐야 진행 통제가 됨
M12타이머 자동 마감한 모둠이 늘어져도 수업이 안 밀리게
M13최종 정산 + 우승 모둠 발표게임의 끝
M14동물 목록·힌트 문구를 시트에서 수정단원마다 테마를 바꿔 질림 방지
M15일시정지 버튼 (리뷰 후 추가)첫 수업에 "잠깐 설명 좀" 순간이 반드시 온다. 타이머 자동 마감은 유지하되 비상구를 남김
M16답 제출·베팅 확정 즉시 기록 (리뷰 후 추가)캐시가 날아가도 "우리 코인 어디 갔어요"가 안 터지게

있으면 좋은 것 (Should — 시간 남으면)

  • 말이 부드럽게 움직이는 달리기 연출
  • 제한시간 카운트다운 소리·효과음
  • 모둠 메모장 (힌트 조합 추론을 적어두는 칸) — 리뷰에서 Must 승격을 제안했으나 Should 유지로 결정. 대신 힌트 글자를 키우고, 모둠에 A4 한 장을 나눠주는 수업 운영으로 대신한다
  • TV에 모둠별 보유 코인 순위 표시

이번엔 안 만드는 것 (Won't)

안 만드는 것이유
한글/엑셀 문제 파일 자동 변환처음엔 손으로 옮겨도 됨. 파일 형식이 제각각이라 만들기 대비 이득이 작음
수업 후 결과 리포트 (모둠별 정답률·오답 통계)게임 자체와 별개 기능. 첫 판에서 빼면 출시가 빨라짐
다른 교사 공유 / 계정 관리 / 문제 분리"나 혼자, 내 반들"로 확정 — 통째로 불필요
학생 개인별 기록·로그인모둠 단위 게임이라 개인 식별이 필요 없음
즉시 반응(실시간 푸시)앱스 스크립트 밖으로 나가야 함. 이 게임에 그만한 값어치가 없음 (§ 02-trd 참조)

5. 잘 됐는지 보는 기준

이 도구는 개인 수업 도구라 매출·가입자 같은 숫자가 없다. 대신 수업에서 눈으로 확인한다.

기준확인 방법
조용하던 학생이 말한다힌트 받은 뒤 모둠 안에서 논쟁이 벌어지는지 교실을 돌며 관찰
어려운 문제에 도전한다라운드가 갈수록 '어려움' 선택 비율이 오르는지 (시트 기록으로 확인 가능)
매번 써도 안 질린다두 번째 단원에 문제·동물만 바꿔 그대로 돌아가는지
준비가 가볍다새 단원 준비가 시트에 문제 18문항 채우기 10분으로 끝나는지
수업이 안 밀린다1차시 안에 3라운드, 2차시 안에 정산까지 끝나는지

6. 원본 PDF에서 뒤집는 것 (중요)

PDF의 프로토타입 코드에는 게임을 무너뜨리는 문제가 있어 아래를 명시적으로 바꾼다.

(1) 말 이동은 랜덤이 아니라 역산이다 — 반드시

PDF 코드는 정답 순위를 랜덤으로 정해두고, 말 이동은 그와 무관하게 매 라운드 0~3칸 난수로 굴린다. 그러면 "A가 최종 1등"이라는 힌트를 뿌려놓고 A가 5등으로 들어오는 판이 실제로 나온다. 힌트가 거짓말이 되면 이 게임은 성립하지 않는다.

→ 정답 순위를 먼저 확정하고, 그 순위대로 도착하도록 각 동물의 라운드별 이동 칸수를 미리 쪼개 놓는다. 중간 순서는 뒤집혀도 되지만(연출), 최종 도착 순서는 정답 순위와 100% 일치한다.

(2) 총 라운드 수를 반쯤 고정한다

PDF는 "3마리가 골인하면 종료"라 몇 라운드에 끝날지 모른다. 2차시 수업에 맞추려면 예측 가능해야 하므로 게임 시작 시 마지막 라운드를 5 또는 6 중 하나로 몰래 정한다. 선생님 화면에는 보이고 학생 화면에는 안 보인다. 언제 끝날지 모르는 긴장은 남고, 수업 시간은 지켜진다.

(3) 힌트는 만든 뒤 검산한다

힌트 전부가 정답 순위 기준으로 참이어야 하고, 게임이 끝날 때까지 모둠들이 받은 힌트를 다 합치면 1·2·3등을 좁힐 수 있어야 한다. 생성 직후 기계가 확인하고, 조건을 못 맞추면 다시 생성한다.

(4) 라운드당 최대 3코인 제한은 실제로 강제한다

PDF 코드는 베팅 버튼을 무한정 누를 수 있다. 라운드당 3코인, 보유 코인 초과 불가를 서버에서 막는다.

(5) 정산을 실제로 계산한다

PDF 코드에는 정산 계산이 아예 없다. 1등 100% / 2등 70% / 3등 50%, 4~8등에 건 코인은 소멸 — 이 규칙대로 최종 화면에서 계산해 보여준다.

6-2. 리뷰에서 지적됐으나 그대로 두기로 한 것

배당률은 최종 배당률 하나만 쓴다 (선생님 결정)

리뷰에서 이런 지적이 나왔다 — 최종 배당률만 쓰면 1라운드에 아무도 안 볼 때 건 모둠과 6라운드에 골인 순서 다 보고 건 모둠이 같은 돈을 받는다. 그러면 "먼저 알아내면 유리하다"는 전제가 약해지고, 코인을 끝까지 쥐고 있다가 마지막에 몰빵하는 게 유리해진다.

그래도 PDF 규칙(최종 배당률)을 유지하기로 했다. 규칙이 단순해야 학생에게 설명이 되고, 실제 경마도 이 방식이다.

대신 첫 수업에서 이걸 본다: 모둠들이 초반 라운드에 코인을 안 쓰고 버티는가? 그러면 다음 중 하나로 조정한다.

  • (가) 라운드별 보너스 배율 — 1라운드에 건 코인은 ×1.5, 6라운드는 ×1.0 (설정 탭 값으로 뺄 수 있게)
  • (나) 라운드당 최소 1코인 베팅 강제
  • (다) 베팅 시점 배당률 고정으로 전환 (데이터 구조 변경 필요 → 그때 결정)

이 조정 여지를 위해 bets 자료에 베팅한 라운드 번호는 처음부터 남겨둔다. 나중에 (가)나 (다)로 갈 때 과거 판을 다시 계산할 수 있다.

7. 정해두고 안 물어본 것 (자동 결정)

  • 수익 모델 없음 — 선생님 개인 구글 계정에서 도는 수업 도구
  • 학생 개인정보 수집 안 함 — 모둠 이름과 4자리 암호만, 이름·학번 저장 안 함
  • 게임 기록은 선생님 구글 드라이브 안에만 남음 (외부 서비스로 안 나감)
  • 화면은 한국어 고정
