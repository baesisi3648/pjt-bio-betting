S1. 교사 — 시작 화면

하는 일: 판을 새로 만들거나, 지난 시간 판을 이어받는다.

Must 기능: M1

보이는 것

  • 제목 "🧬 와일드 더비"
  • 탭 두 개: 새 판 만들기 / 판 코드로 이어하기
  • [새 판 만들기]
    • 반 이름 입력 (예: 2학년 3반)
    • 단원 고르기 (드롭다운 — 문제 탭의 A열에서 자동으로 목록을 뽑음)
    • 모둠 수 고르기 (2~8)
    • 모둠 이름 입력칸 (모둠 수만큼 생김. 비우면 1모둠, 2모둠…)
    • 판 만들기 버튼
  • [판 코드로 이어하기]
    • 판 코드 4자리 입력 + 이어하기 버튼
    • 아래에 최근 판 목록 (반 이름 / 만든 날짜 / 몇 라운드까지 갔는지 / 끝났는지)

판을 만든 직후 보이는 것 (이게 제일 중요)

판 코드      2H4K        ← 아주 크게. 칠판에 적을 것
학생 주소    ...exec      ← 아주 크게 (QR은 이번 범위 밖 — 외부 라이브러리 금지 원칙)

모둠별 암호 (모둠장에게만 알려주세요)
  1모둠 미토콘드리아  4821
  2모둠 엽록체        1937
  ...
                      [인쇄하기]  [진행 화면으로]

필요한 데이터: 문제 탭 단원 목록, 동물 탭, 설정 탭

막아야 하는 것

  • 문항 부족: "유전 단원 — 어려움 4문항 부족(2/6). 그래도 시작할까요?" → 계속/취소
  • 동물 탭이 8줄이 아님: 시작 불가, 고치라고 안내
  • 힌트문구 탭에 {X} 자리표시가 깨짐: 시작 불가, 어느 줄인지 알려줌
  • 모둠 이름 중복: 뒤에 번호 자동으로 붙임

비었을 때: 이어하기 목록이 비면 "아직 만든 판이 없어요. 새 판을 만들어 보세요."

S2. 교사 — 진행 화면

하는 일: 수업 내내 TV에 띄워두는 화면. 게임의 중계석.

Must 기능: M9, M10, M11, M12, M15

화면 배치 (1920×1080)

┌──────────────────────────────────────────────────────────┐
│ 🧬 와일드 더비   2학년 3반 · 유전        3라운드      ⏱ 47 │
├──────────────────────────────────────────────────────────┤
│ [🐆 치타 ] ▓▓▓▓▓▓░░░░ 🏁                                  │
│ [🦁 사자 ] ▓▓▓▓░░░░░░ 🏁                                  │
│ ... 8줄 ...                                    (화면 절반) │
├────────────────────────────┬─────────────────────────────┤
│ 배당률 전광판                │ 모둠 현황                    │
│ 🐆 치타   12코인   2.14배   │ 1모둠 미토콘드리아 ✅ 💰      │
│ 🦁 사자    3코인   5.80배   │ 2모둠 엽록체       ⏳ ⏳      │
│ ...                        │ ...                          │
├────────────────────────────┴─────────────────────────────┤
│  [라운드 시작]  [⏸ 일시정지]   (작게) 정답 순위 보기 · 정산 │
└──────────────────────────────────────────────────────────┘

⏸ 일시정지 (리뷰 반영) — 누르면 타이머가 멈추고, 학생 화면에도 "선생님이 잠시 멈췄어요"가 뜬다. 멈춘 동안 답 제출·베팅이 거부된다. 다시 누르면 멈춘 지점의 남은 시간부터 이어간다. 자동 마감 방침은 그대로 두고 비상구만 남기는 것이다.

단계마다 달라지는 것

단계화면
waiting가운데 크게 "3라운드 준비 — [라운드 시작]"
moving말이 움직임 (0.6초). 타이머 없음
quiz상단에 "문제 푸는 중" + 타이머. 모둠 현황의 제출 표시가 하나씩 켜짐
discuss상단에 "모둠 토론 중" + 타이머. 트랙·전광판은 그대로, 조작 없음
betting상단에 "베팅 중" + 타이머. 전광판이 계속 움직임
paused타이머가 멈춘 채 회색 덮개 + "일시정지 중"
done정산 화면으로 넘어가는 버튼만 크게

"정답 순위 보기" — 선생님만. 누르면 비밀번호 없이 바로 뜨지만, 작고 눈에 안 띄게 둔다 (실수로 TV에 띄우지 않게). 뜰 때는 반투명 덮개로 트랙을 가린다.

필요한 데이터: 게임 상태 전체 (교사 권한)

막아야 하는 것

  • 라운드 진행 중에 라운드 시작 다시 누르기 → 버튼 잠금
  • 마지막 라운드가 안 끝났는데 정산하기 → "아직 3등이 안 들어왔어요. 그래도 정산할까요?" 확인
  • 서버 응답 실패 3회 연속 → 화면 상단에 빨간 띠 "연결이 불안정해요. 인터넷을 확인해주세요"

S3. 교사 — 정산 화면

하는 일: 정답 공개하고 우승 모둠을 발표한다. 수업의 절정.

Must 기능: M13

보이는 순서 (선생님이 한 단계씩 넘김 — 한 번에 다 보여주면 김빠짐)

1단계  최종 순위 공개
       🥇 1등 호랑이(C)   🥈 2등 치타(A)   🥉 3등 타조(F)
       (4~8등도 아래에 작게)

2단계  모둠별 계산 내역
       1모둠 미토콘드리아
         치타(2등)에 4코인 × 2.14배 × 70% =  5.9 → 6코인
         사자(6등)에 2코인                  =  0코인
         남은 코인 8 + 획득 6              = 14코인

3단계  최종 순위 발표
       🏆 3모둠 리보솜  27코인
          1모둠 미토콘드리아 14코인
          ...

추가로: 이번 게임 문제 다시보기 — 라운드별 문제·정답·해설을 띄운다. 오답 짚어주는 용도. (문제·정답·해설은 이미 시트에 있으므로 만들기 부담 작음)

필요한 데이터: 게임 상태 전체 + 문제 탭 해설

S4. 모둠 — 접속 화면

하는 일: 우리 모둠으로 들어간다.

Must 기능: M5

단계 3개 (한 화면에 하나씩)

1) 판 코드 4자리        [ 2 H 4 K ]
2) 우리 모둠 고르기      1모둠 ● / 2모둠 ● / 3모둠 ●   (전부 선택 가능)
3) 암호 4자리           [ 4 8 2 1 ]

접속 점유는 두지 않는다 (리뷰 반영). 처음 설계에는 "다른 폰이 잡은 모둠은 회색"이 있었는데, 그러면 새로고침한 폰이 자기 자신 때문에 재접속을 못 한다. 수업 중 이게 터지면 그 모둠은 게임에서 이탈한다.

→ 암호만 맞으면 몇 대든 들어온다. 모둠이 폰 2대를 쓰고 싶을 수도 있고, 어차피 방어선은 암호다.

막아야 하는 것

  • 없는 판 코드: "그런 판이 없어요. 칠판의 코드를 다시 확인해주세요"
  • 이미 끝난 판: "이 판은 이미 끝났어요"
  • 암호 틀림: "암호가 달라요. 모둠장에게 확인해주세요" — 잠금은 두지 않고 시도마다 1초씩 지연만 준다 (모둠 단위로 잠그면 장난치는 학생이 남의 모둠을 계속 잠글 수 있다)
  • 새로고침·재접속: 같은 셋을 다시 넣으면 그대로 복구 (힌트·코인 유지)

주의: 학생 이름이나 학번은 받지 않는다.

S5. 모둠 — 게임 화면

하는 일: 문제 풀고, 힌트 보고, 베팅한다. 학생이 45분 내내 보는 화면.

Must 기능: M6, M7, M8, M12, M15

구조

┌────────────────────────────┐
│ ▓▓▓▓▓▓▓░░░  남은 47초       │ ← 타이머 막대
│ 지금은 ▸ 베팅할 때예요       │ ← 지금 뭘 할 때인지 (상단!)
│ 3모둠 리보솜      💰 14코인  │
├────────────────────────────┤
│  [문제]   [힌트 3]  [베팅]   │ ← 탭. 지금 할 일에 점 표시
├────────────────────────────┤
│                            │
│         (탭 내용)           │
│                            │
└────────────────────────────┘
"지금 뭘 할 때인지"는 상단 타이머 바로 아래에 둔다. 처음엔 하단에 두려 했으나, 폰에서 하단은 잘 안 본다 (리뷰 반영). 일시정지 중에는 이 자리에 "선생님이 잠시 멈췄어요"가 뜨고 탭 전체가 흐려진다.

탭 1 — 문제

상태화면
아직 안 고름난이도 버튼 3개 (쉬움/중간/어려움) + "어려울수록 좋은 힌트"
고른 뒤문제 + 4지선다 + 제출
제출함⭕ 정답! → "힌트 탭에 새 힌트가 도착했어요" / ❌ 오답 → 정답과 해설 표시
시간 끝"시간이 지났어요. 다음 라운드를 기다려주세요"
이번 라운드 아님"지금은 {단계} 시간이에요"
  • 난이도는 한 라운드에 한 번만. 고르기 전 확인 한 번
  • 제출도 한 번만. 제출 후 잠김

탭 2 — 힌트 (게임의 심장)

  • 지금까지 받은 힌트 전부, 최신이 위로
  • 각 카드에 몇 라운드 · 난이도
  • 아직 없으면: "문제를 맞히면 힌트를 받아요"
  • 새 힌트가 오면 탭 이름에 숫자 배지
이 탭이 모둠 토론의 무대다. 스크롤 없이 6개까지 한눈에 들어오는 게 목표. 토론 단계(180초)에는 이 탭이 자동으로 열리고 베팅이 잠긴다 — 조작할 게 없어야 서로 본다.

탭 3 — 베팅

  • 동물 8마리 + 그림 + 현재 배당률 + −/+/현재 건 코인
  • 하단: "이번 라운드 3개 중 2개 사용" / 베팅 확정하기
  • 확정 후 잠김. 확정 전 확인 한 번
  • 지난 라운드에 건 것도 아래에 작게 (누적 얼마 걸었는지)

막아야 하는 것

  • 3코인 초과: + 흐려짐
  • 보유 코인 초과: + 흐려짐
  • 시간 지난 뒤 제출: 서버가 거부 → "베팅 시간이 지났어요"
  • 두 번 누르기: 서버 응답까지 버튼 잠금

절대 안 보이는 것: 정답 순위, 다른 모둠 힌트, 다른 모둠이 뭘 골랐는지, 마지막 라운드가 몇인지

S6. 모둠 — 결과 화면

하는 일: 우리 모둠이 어떻게 됐는지 본다.

  • 최종 순위 (1·2·3등 동물)
  • 우리가 맞힌 것 / 놓친 것
  • 획득 코인 계산 내역
  • 전체 모둠 중 우리 등수
  • (있으면 좋은 것) "우리가 받은 힌트로 답을 좁힐 수 있었을까?" 되짚어보기 — 이번 범위 밖
