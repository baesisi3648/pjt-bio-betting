핵심 결정 두 가지

  1. Game.gs를 순수 함수로 격리해서 앱스 스크립트 밖(node)에서 그대로 테스트할 수 있게 했습니다. 앱스 스크립트에는 테스트 도구가 없어서, 이게 아니었으면 H1~H3를 확인할 방법이 없었습니다.
  2. 사건을 즉시 기록하고 캐시 소실 시 재생해 복구합니다. 라운드 끝에 몰아 쓰는 원래 설계였다면 캐시가 날아갈 때 그 라운드가 통째로 증발했을 겁니다.
