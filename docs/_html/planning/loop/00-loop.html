루프 차터 — 와일드 더비

이 프로젝트에서 "완료"란 무엇인가를 정한 문서. 08-derived-gates.md와 함께 완료 기준이 된다.

이 프로젝트의 성격

항목값
무엇고2 생명과학 단원 마무리용 베팅 레이스 보드게임
어디서교실 (TV 1대 + 모둠 폰 5~6대), 학교 구글 계정
누가선생님 혼자 만들고 혼자 운영. 다른 사용자 없음
무엇으로Google Apps Script + 스프레드시트
실패의 모습수업 중에 안 돌아가서 30명 앞에서 멈추는 것

이 마지막 줄이 모든 우선순위를 정한다. 예쁜 것보다 안 멈추는 것이 먼저다.

완료의 정의

  1. 08-derived-gates.md의 Hard 게이트 전부를 증거와 함께 통과
  2. Metric 게이트가 목표 안에 들어옴
  3. Domain 게이트 전부 통과
  4. Rubric은 첫 수업 후 판정 — 통과 전이라도 배포는 가능하되, R-1(조용하던 학생이 말하는가)이 3점 미만이면 기획을 다시 본다
구현자의 "됐습니다"는 완료가 아니다. 게이트별 증거가 완료다.

이 프로젝트에서 특히 조심할 것

1. 되돌리면 게임이 무너지는 결정 4개

무심코 "단순하게" 고치면 게임이 통째로 망가지는 곳들이다. 코드에 주석으로 박아둘 것.

결정되돌리면
이동을 순위에서 역산힌트가 거짓말이 된다 (PDF 원본의 버그)
toTeamView로 비밀 제거개발자 도구로 정답이 보인다
답·베팅 즉시 기록캐시 소실 시 수업 중 코인이 증발한다
접속 점유를 두지 않음새로고침한 모둠이 자기 자신 때문에 이탈한다

2. 첫 수업 전 반드시 하는 것

  • 코드 고쳤으면 새 버전으로 재배포 (제일 흔한 사고)
  • 학교 와이파이 폰으로 학생 주소 열어보기 (H10)
  • 이번 단원 문항 18개 이상 확인
  • 모둠별 암호 인쇄

3. 첫 수업 후 조정할 값 (설정 탭)

값기본조정 신호
시드코인15배당이 여전히 튀면 20, 밋밋하면 10
문제시간초90남으면 줄이고 모자라면 늘림
토론시간초180대화가 안 붙으면 늘림
베팅시간초60허둥대면 늘림

루프 규칙

  • 최대 3라운드. 3회 후에도 핵심 게이트 미달이면 통과시키지 않고 잔존 리스크로 명시한다
  • 검증은 빌드를 수행하지 않은 쪽이 한다 (구현자 자기 검증 금지)
  • 게이트 실패 시 rework-request-NN.md에 실패한 게이트 + 증거를 적어 되돌린다
  • 문서를 통째로 다시 쓰지 않는다. 지목된 부분만 고친다

상위 원칙과의 연결

상위 원칙이 프로젝트에서의 뜻
증거 없이 완료 선언 금지Test.gs 실행 로그 원문이 있어야 통과
있는 척 금지안 만든 것은 Won't에 적혀 있다. 만든 척하지 않는다
최소 패치감독 라운드에서 문서를 다시 쓰지 않고 지목 부분만 고쳤다
사용자 결정 존중배당 방식(최종 배당률)은 리뷰 권장과 달라도 선생님 결정을 따른다. 대신 전환 가능하게 데이터를 남긴다
