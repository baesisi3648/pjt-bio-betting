# 🧬 생명과학 와일드 더비

고2 생명과학 단원 마무리 차시용 베팅 레이스 보드게임. 구글 스프레드시트 + 앱스 스크립트로 돕니다.

> 모둠이 난이도를 골라 문제를 풀고, 맞히면 **순위 힌트**를 받고, 그 단서로 1·2·3등을 추리해 코인을 겁니다.
> 문제 풀이는 수단이고, 진짜 수업은 **힌트를 받은 뒤 모둠이 이야기하는 3분**에 일어납니다.

---

## 준비 (처음 한 번, 약 15분)

### 1. 스프레드시트 만들기

1. 구글 드라이브 → 새로 만들기 → **Google 스프레드시트**
2. 이름을 `와일드더비`로
3. 상단 메뉴 **확장 프로그램 → Apps Script**

### 2. 코드 붙여넣기

편집기 왼쪽 `+` 버튼으로 파일을 만들고, `apps-script/` 폴더의 내용을 그대로 붙여넣습니다.

| 만들 파일 | 종류 | 원본 |
|---|---|---|
| `Config` | 스크립트 | `apps-script/Config.gs` |
| `Game` | 스크립트 | `apps-script/Game.gs` |
| `Sheet` | 스크립트 | `apps-script/Sheet.gs` |
| `Code` | 스크립트 | `apps-script/Code.gs` (기본 `Code.gs`를 지우고 덮어쓰기) |
| `Setup` | 스크립트 | `apps-script/Setup.gs` |
| `Test` | 스크립트 | `apps-script/Test.gs` |
| `Shared` | **HTML** | `apps-script/Shared.html` |
| `Teacher` | **HTML** | `apps-script/Teacher.html` |
| `Team` | **HTML** | `apps-script/Team.html` |

저장(⌘S / Ctrl+S).

### 3. 시트 준비

1. 편집기 상단 함수 목록에서 `setupSheets` 선택 → **실행**
2. 처음이면 권한 승인 창 → 계정 선택 → `고급` → `(안전하지 않음)으로 이동` → `허용`
3. 스프레드시트로 돌아가면 탭 6개가 만들어져 있습니다

개발용 샘플 문제를 넣어보려면 `insertSampleQuestions`도 한 번 실행하세요 (유전 단원 18문항).

### 4. 검사 돌리기

`test_모두` 실행 → 로그(Ctrl+Enter)에서 전부 `PASS`인지 확인합니다. 하나라도 `FAIL`이면 수업에 쓰지 마세요.

### 5. 웹앱 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 설정
   - 설명: `와일드 더비`
   - 실행 계정: **나(소유자)**
   - 액세스 권한: **링크가 있는 모든 사용자** ← 학생이 로그인 없이 들어와야 하므로 필수
4. **배포** → 나온 주소를 복사

주소 두 개를 씁니다.

| 용도 | 주소 |
|---|---|
| 선생님 (TV) | `<복사한 주소>?role=teacher` |
| 학생 (모둠 폰) | `<복사한 주소>` |

> ⚠️ **코드를 고칠 때마다** `배포 관리 → 편집 → 버전: 새 버전 → 배포`를 다시 해야 반영됩니다.
> 이걸 잊는 게 제일 흔한 사고라, 화면 맨 아래에 배포 버전을 표시해 뒀습니다.

---

## 수업 준비 (단원마다, 약 10분)

`문제` 탭에 이번 단원 문제를 넣습니다.

| 단원 | 난이도 | 문제 | 보기1~4 | 정답 | 해설 |
|---|---|---|---|---|---|
| 유전 | 어려움 | … | … | 1~4 | (비워도 됨) |

- 난이도는 `쉬움` / `중간` / `어려움` 셋 중 하나 (다르게 쓰면 무시됩니다)
- 정답은 보기 번호 **1~4**
- 한 단원에 **난이도별 6문항, 총 18문항**이면 충분합니다. 모자라면 시작할 때 알려주고, 앞 라운드 문제를 다시 냅니다

동물과 힌트 문구도 `동물`·`힌트문구` 탭에서 바꿀 수 있습니다. 단원마다 세포소기관·효소·생태계 생물로 갈아 끼우면 질리지 않습니다.

## 수업 진행

### 1차시 (50분)

1. 선생님 주소를 TV에 띄우고 **새 판 만들기** → 반 이름·단원·모둠 수 입력
2. 나온 **판 코드 4자리를 칠판에**, **모둠별 암호는 인쇄해서 모둠장에게만**
3. 학생들이 폰으로 접속 (판 코드 → 모둠 → 암호)
4. `🎲 라운드 시작` → 라운드가 자동으로 흘러갑니다

> **판 코드는 비밀이 아닙니다.** 칠판에 적혀 있으니까요.
> 교사 화면임을 증명하는 것은 판을 만들 때 발급되는 **교사 열쇠**이고,
> 이건 판을 만든 그 브라우저에 저장됩니다. 같은 기기·같은 브라우저로 이어하면 신경 쓸 일이 없습니다.

한 라운드는 약 7분입니다.

```
말 이동 20초 → 문제 풀이 90초 → 모둠 토론 180초 → 베팅 60초
```

**토론 180초가 이 수업의 핵심입니다.** 그동안 학생 화면은 힌트 탭이 열리고 베팅이 잠깁니다 — 조작할 게 없어야 서로 봅니다. 이때 교실을 돌아다니며 들어보세요.

3~4라운드쯤에서 종이 치면 **판 코드를 칠판에 크게 띄우고** 마칩니다. 자동으로 저장됩니다.

### 2차시 (50분)

1. **판 코드로 이어하기** → 지난 시간 그대로 복원
2. 남은 라운드 진행
3. `정산하기` → 순위를 하나씩 공개하고 우승 모둠 발표

**다른 기기에서 이어하려면** 교사 열쇠가 필요합니다.
스프레드시트 상단 메뉴 **와일드 더비 → 교사 열쇠 확인** 에서 판 코드를 넣으면 열쇠가 나옵니다.
(학생에게는 보여주지 마세요 — 이 열쇠로 정답 순위와 모둠 암호를 볼 수 있습니다.)

`⏸ 일시정지`는 언제든 누를 수 있습니다. 설명할 게 생기면 쓰세요.

## 수업 전 5분 점검

- [ ] 코드를 고쳤다면 **새 버전으로 재배포**했는가 (제일 흔한 사고)
- [ ] 화면 맨 아래 배포 버전이 오늘 것인가
- [ ] 이번 단원 문항이 18개 이상인가
- [ ] **내 폰(학교 와이파이)에서 학생 주소가 열리는가** ← 학교망 차단 확인
- [ ] 지난 판을 이어한다면, 그 판을 만든 기기인가 (아니면 교사 열쇠를 미리 받아두기)
- [ ] 모둠별 암호를 인쇄했는가
- [ ] TV에 화면이 잘리지 않고 뜨는가

### 코드를 고쳤을 때

```bash
npm test          # 검사부터 (게이트 32개) — FAIL이면 올리지 말 것
npm run deploy    # 코드 올리고 같은 주소로 갱신
```

`npm run deploy`는 push → 새 버전 생성 → **기존 배포를 갱신**까지 한 번에 합니다.
주소가 바뀌지 않으므로 칠판에 적어둔 학생 주소를 다시 안내할 필요가 없습니다.

> ⚠️ `clasp create-deployment`(새 배포)를 쓰면 **주소가 새로 생깁니다.** 학생들이 옛 주소로
> 들어오게 되니, 고칠 때는 위 명령을 쓰세요.

## 개발자용

```bash
node test/run-gates.js      # 게임 규칙 게이트 17개
node test/simulate-game.js  # 전체 판 통합 시뮬레이션 14개
```

`Game.gs`는 순수 함수만 담아서 앱스 스크립트 밖(node)에서도 그대로 돌아갑니다.

### 되돌리면 게임이 무너지는 곳 4개

무심코 "단순하게" 고치면 통째로 망가지는 자리들입니다. 코드에 ⚠️ 주석이 달려 있습니다.

| 자리 | 되돌리면 |
|---|---|
| `Game.gs planRace` — 순위에서 이동을 **역산** | 힌트가 거짓말이 됩니다 |
| `Code.gs teamView` — 비밀 **제거** | 개발자 도구로 정답이 보입니다 |
| `Sheet.gs appendEvent` — 답·베팅 **즉시 기록** | 캐시 소실 시 수업 중 코인이 증발합니다 |
| `Code.gs gwJoinGame` — 접속 점유를 **두지 않음** | 새로고침한 모둠이 자기 자신 때문에 이탈합니다 |
