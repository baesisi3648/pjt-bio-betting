규칙은 30초면 이해됩니다.

  • 동물 8마리가 20칸 트랙을 달립니다. 최종 1·2·3등이 누구인지는 게임이 끝날 때 공개됩니다.
  • 모둠은 라운드마다 문제를 하나 풉니다. 난이도를 고르고, 맞히면 순위 힌트를 받습니다. 어려운 문제일수록 힌트가 구체적입니다.
  • 힌트를 모아 추리한 뒤 동물에 코인을 겁니다. 라운드당 최대 3개.
  • 2~4라운드 중 한 라운드는 힌트가 전부 거짓입니다. 어느 라운드인지는 아무도 모릅니다. 서로 어긋나는 힌트를 찾아 거짓을 가려내는 게 이 게임의 재미입니다.
  • 마지막에 정산합니다. 1등에 건 코인은 배당률의 100%, 2등은 70%, 3등은 50%를 받습니다. 나머지는 잃습니다.
  • 가장 코인이 많은 모둠이 우승.
이 게임의 핵심은 토론입니다

토론 시간에는 폰에 누를 것이 없습니다. 힌트를 놓고 모둠끼리 "3라운드 힌트가 이상한데?" 하고 이야기하는 시간이라서 그래요. 혼자 해 볼 때 길게 느껴지면 선생님 화면의 ⏩ 빠른 진행으로 바로 넘길 수 있습니다.

  1. 난이도를 고릅니다: 쉬움 · 보통 · 어려움. 한 번 고르면 이 라운드에는 못 바꿉니다.

8

모둠 토론 (90초) 둘 다

폰은 힌트 탭이 열리고 조용합니다. 지금까지 받은 힌트를 늘어놓고 서로 어긋나는 것을 찾으세요. 2라운드 힌트가 "치타는 1등이 아님"인데 4라운드 힌트가 "1등은 치타 또는 토끼"라면 둘 중 하나는 거짓 라운드입니다. 다른 힌트와 맞춰 보면 어느 쪽인지 좁혀집니다.

혼자 해 볼 때 90초가 길면 노트북에서 ⏩ 빠른 진행. 토론은 자동으로는 절대 짧아지지 않아요.

9

베팅 (45초) 폰

베팅 탭에서 동물 옆 +를 누르면 칩이 쌓입니다. 한 라운드에 최대 3코인, 여러 동물에 나눠 걸 수 있어요. 💰 N코인 걸기 → 확인하면 되돌릴 수 없습니다.

이미 골인한 동물에는 걸 수 없습니다. 그 줄은 🏁 골인으로 잠겨요. 1등이 8라운드쯤 먼저 들어오면 그 뒤 베팅은 아직 안 들어온 2·3등 후보를 맞히는 싸움이 됩니다.

확정하는 순간 칩이 날아가고 "📺 TV를 보세요"가 뜹니다. 노트북 배당판이 그 즉시 움직여요. 코인이 몰린 동물의 배당률은 내려가고(▼), 나머지는 올라갑니다(▲). 모든 모둠이 확정하면 5초 뒤 자동으로 다음으로.

10

다음 라운드 노트북

버튼이 ▶ ROUND 2 시작이 됩니다. 누르면 6번부터 반복. 헤더의 ①~⑩ 진행표가 채워집니다. 1등은 8~9라운드에, 3등까지는 늦어도 10라운드에 골인하고 3등이 들어오면 경주가 끝납니다. 그러면 시작 버튼이 사라지고 결과 확인만 남아요.

정답 공개와 계산 노트북

  1. 오른쪽 아래 결과 확인 → 확인.
  2. 다음 순위 공개를 누르면 스포트라이트가 3등 → 2등 → 1등 순서로 한 마리씩 비춥니다.
  3. 모둠별 계산 보기: 각 모둠의 코인이 올라가거나 내려갑니다. 줄을 펼치면 계산식이 보여요.
  4. 우승 발표: 컨페티와 함께 1위 모둠. 그리고 "🎭 N라운드 힌트는 거짓이었습니다"가 공개됩니다. 폰에도 뜹니다.
배당 계산법

동물에 건 코인 × 그 동물의 배당률 × (1등 100% / 2등 70% / 3등 50%). 4등 밑에 건 코인은 0. 배당률은 정산 시점의 최종 판돈으로 계산됩니다.

6문제 넣기 (다른 과목으로 쓰려면)

주소 뒤에 /admin을 붙이면 문제 관리자가 열립니다. 관리자 비밀번호 필요.

  • 문제 세트 단위로 관리합니다. 세트 이름은 "한국사 핵심 개념", "영어 어휘 챌린지"처럼 아무거나.
  • JSON 가져오기로 파일 하나에 30문항을 한 번에 넣을 수 있습니다. 먼저 요약(총 개수·난이도별·오류 줄)을 보여주고, 기존에 추가 / 같은 이름 세트 교체 / 전체 교체 중 고릅니다. JSON 내보내기로 백업하거나 다른 선생님에게 줄 수 있어요.
  • 객관식만 됩니다. 보기 4개, 정답 번호, 난이도(쉬움·보통·어려움), 해설(선택).
  • 여기서 고친 문제는 새로 만드는 방부터 적용됩니다. 이미 도는 방은 만들 때의 문제를 그대로 씁니다.
JSON 형식
{ "title": "세트 이름", "questions": [ { "difficulty": "easy", "question": "…", "choices": ["…","…","…","…"], "answer": 2, "explanation": "…" } ] }
difficulty 는 easy · medium · hard (쉬움·보통·어려움으로 적어도 됨), answer 는 1~4

7막히면 여기

"관리자 비밀번호가 달라요"가 떠요

영문·숫자만이고 대소문자를 구분합니다. 형/누나에게 받은 값 그대로 넣어야 해요.

노트북을 새로고침했더니 방이 사라졌어요

사라진 게 아니에요. 첫 페이지의 판 코드로 이어하기에 판 코드를 넣으면 돌아갑니다. 다른 기기라면 관리자 비밀번호를 한 번 더 물어봅니다. 진행 상황은 전부 서버에 있어서 폰들도 그대로 연결돼 있어요.

폰에 "연결이 불안정해요" 빨간 띠가 떠요

와이파이가 잠깐 끊긴 거예요. 1~15초 안에 스스로 다시 붙고, 붙으면 띠가 사라지면서 화면이 최신 상태로 맞춰집니다.

"암호를 여러 번 틀렸어요. 30초 뒤에 다시 해주세요"

같은 모둠 암호를 5번 연속 틀리면 그 모둠만 30초 잠깁니다. 노트북의 '학생 주소·암호'에서 암호를 확인하고 다시 넣으세요.

소리가 안 나요

브라우저는 첫 클릭 전에는 소리를 못 냅니다. 라운드 시작 버튼을 누른 뒤에 켜져요. 우상단 🎵를 눌러 음소거가 아닌지, 볼륨이 0이 아닌지 보세요. 폰은 원래 소리가 안 납니다.

골인한 동물에 걸고 싶은데 버튼이 없어요

규칙입니다. 이미 결승선을 넘은 동물은 순위가 사실상 드러났으니 더 걸 수 없어요. 이미 건 코인은 그대로 남습니다.

경주 애니메이션이 안 나오고 말이 그냥 옮겨져요

그 기기가 그래픽 가속(WebGL)을 못 쓰거나, 시스템 설정에 '동작 줄이기'가 켜져 있으면 단순 화면으로 바뀝니다. 게임은 똑같이 돌아가요.

정답을 미리 보고 싶어요

노트북 맨 아래 정답 순위 보기. 선생님만 볼 수 있고 학생 폰에는 절대 안 나갑니다. 거짓 라운드가 몇 라운드인지도 정산 전에는 폰으로 나가지 않아요.
